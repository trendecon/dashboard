About ​

trendEcon started in March 2020 as a response to the Covid-19 pandemic, when the need for timely economic indicators became acute. It is a collaborative, open-source project.

Partners ​

  • cynkra
  • KOF Swiss Economic Institute, ETH Zurich
  • State Secretariat for Economic Affairs (SECO)
  • Swiss Federation of Trade Unions (SGB)
  • University of St. Gallen

Open data & code ​

  • Method: trendecon R package
  • Daily data: github.com/trendecon/data
  • Paper: Economic Inquiry 60(2), 694–705

Data and code are released under CC BY 4.0 / GPL-3.0.
