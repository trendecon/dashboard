# About

trendEcon started in March 2020 as a response to the Covid-19 pandemic, when the
need for timely economic indicators became acute. It is a collaborative,
open-source project.

## Partners

- [cynkra](https://cynkra.com)
- [KOF Swiss Economic Institute](https://kof.ethz.ch/en/), ETH Zurich
- State Secretariat for Economic Affairs ([SECO](https://www.seco.admin.ch/seco/en/home/wirtschaftslage---wirtschaftspolitik/Wirtschaftslage/konjunkturprognosen.html))
- Swiss Federation of Trade Unions ([SGB](https://www.sgb.ch/aktuell))
- [University of St. Gallen](https://siaw.unisg.ch/)

## Open data & code

- **Method:** [`trendecon` R package](https://trendecon.github.io/trendecon/)
- **Daily data:** [github.com/trendecon/data](https://github.com/trendecon/data)
- **Paper:** [Economic Inquiry 60(2), 694–705](https://doi.org/10.1111/ecin.13049)

Data and code are released under CC BY 4.0 / GPL-3.0.
